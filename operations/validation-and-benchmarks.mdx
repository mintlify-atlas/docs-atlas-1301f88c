AgentCore ships native C++ tests, Python smoke tests, and benchmark executables. Pick the validation lane that matches the scope of your change — you don't need to run everything after every edit.

## Validation lanes

| Change type | Suggested first pass |
|---|---|
| Python graph API or examples | Local build + Python smoke tests |
| Scheduler, state, checkpoint, or replay behavior | `release-perf` build + `ctest` + native benchmarks |
| MCP or OpenTelemetry integration | Python smoke tests |
| Published package candidate | Wheel smoke + clean install test |
| Benchmark document update | Rerun with `release-perf` build, keep build type visible |

## Full validation pass

<Steps>
  <Step title="Build with the release-perf preset">
    ```bash
    cmake --preset release-perf
    cmake --build --preset release-perf -j
    ```
  </Step>
  <Step title="Run the native test suite">
    ```bash
    ctest --preset release-perf
    ```
  </Step>
  <Step title="Run native benchmarks">
    ```bash
    ./build/release-perf/agentcore_runtime_benchmark
    ./build/release-perf/agentcore_persistent_subgraph_session_benchmark
    ```
  </Step>
  <Step title="Build Python bindings">
    ```bash
    cmake -S . -B build -DAGENTCORE_BUILD_PYTHON_BINDINGS=ON -DAGENTCORE_BUILD_BENCHMARKS=ON
    cmake --build build -j
    ```
  </Step>
  <Step title="Run Python smoke tests">
    ```bash
    PYTHONPATH=./build/python python3 ./python/tests/state_graph_api_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/agent_workflows_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/patterns_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/adapters_runtime_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/mcp_runtime_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/context_state_smoke.py
    PYTHONPATH=./build/python python3 ./python/tests/real_world_pipeline_test.py
    PYTHONPATH=./build/python python3 ./python/tests/graph_store_pipeline_test.py
    ```
  </Step>
  <Step title="Run the LangGraph head-to-head benchmark">
    ```bash
    python3 -m pip install "langgraph==0.6.11"
    AGENTCORE_BUILD_PYTHON_ROOT=./build/release-perf/python python3 \
      ./python/benchmarks/langgraph_head_to_head.py
    ```
    For machine-readable output:
    ```bash
    AGENTCORE_BUILD_PYTHON_ROOT=./build/release-perf/python python3 \
      ./python/benchmarks/langgraph_head_to_head.py --format json
    ```
  </Step>
</Steps>

## Native regression benchmark coverage

The native benchmarks are structural regression gates, not just timing measurements. They assert correctness invariants alongside performance counters.

Key coverage areas:

- **Context-graph ranking** — cold build and warm cached ranking over tasks, claims, evidence, decisions, memories, and knowledge triples. Sample counters: `context_graph_cold_rank_ns`, `context_graph_warm_rank_avg_ns`
- **Knowledge ingestion** — batched entity/triple commits, exact-match lookup, final store cardinality. Counters: `knowledge_ingest_triples`, `knowledge_ingest_batches`, `knowledge_ingest_exact_matched`
- **Deterministic memoization** — verifies executor invocations collapse to 1 on stable declared inputs, and remain at the full visit count when a declared key changes
- **Persistent session replay** — asserts equal final state and equal proof digest between uninterrupted and resumed runs, plus expected committed session counts and no duplicate once-only producer calls
- **Recorded effects** — hit/miss cost for the task-journal seam
- **Stream cursor cost** — read cost for public stream event access
